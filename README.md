# 💎 FalStore Premium Apps (`aplikasi-premium`)

Platform e-commerce digital store modern untuk penjualan akun & langganan aplikasi premium resmi dan bergaransi (Canva Pro, ChatGPT Plus, YouTube Premium, Netflix 4K, Spotify Premium, CapCut Pro, Claude Pro, Microsoft 365).

---

## ✨ Fitur Utama

- 🎨 **Katalog Aplikasi Lengkap:**
  - **Desain & Kreatif:** Canva Pro 1 Tahun, CapCut Pro Cloud 100GB.
  - **Artificial Intelligence (AI):** ChatGPT Plus (GPT-4o), Claude Pro (Claude 3.5 Sonnet).
  - **Streaming & Hiburan:** YouTube Premium & Music (No Ads), Netflix UHD 4K (Private PIN), Spotify Premium.
  - **Produktivitas:** Microsoft 365 Pro + 1TB OneDrive Cloud Storage.
- ⚡ **Pengiriman Instan Digital:**
  - Pengiriman via WhatsApp (0-5 Menit), Email Invite Link, atau Telegram Bot.
  - Bebas ongkos kirim (Rp 0).
- 🔒 **Sistem Login 1-Klik (Zero-Typing):**
  - Google One-Tap, WhatsApp Direct Handshake (`085182555842`), dan Telegram Auth.
- 🛡️ **Panel Admin Tersembunyi (`/admin`):**
  - Akses terproteksi PIN Admin (`2026`).
  - Manajemen pesanan masuk, pembaruan status aktivasi, metrik omset real-time, dan penambahan katalog aplikasi.
- 💳 **Pembayaran Terintegrasi:**
  - QRIS Otomatis (BCA, Mandiri, GoPay, OVO, ShopeePay, Dana) & Virtual Account Bank.
- 📱 **Mobile-First UX:**
  - Bottom navigation bar responsif, touch-optimized stepper kuantitas, dan modal ramah layar sentuh.

---

## 🛠️ Stack Teknologi

- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL 16
- **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS, Lucide Icons, Google Fonts (Instrument Serif & Inter)
- **Deployment:** UpCloud VPS (Singapore SG-SIN1), Systemd Service, Nginx Reverse Proxy, Cloudflare TLS 1.3

---

## 🚀 Cara Menjalankan Secara Lokal

```bash
# Clone repository
git clone https://github.com/23041450154/aplikasi-premium.git
cd aplikasi-premium

# Install dependencies
npm install

# Jalankan server
node server.js
```

Akses di browser: `http://localhost:3001` atau `http://localhost:3001/admin`.
